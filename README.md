# Design-and-Development-of-a-3D-Printed-Self-Solving-Rubik-s-Cube-Robot
This project transcends the traditional task of puzzle-solving by framing the Rubik’s Cube as a complex mechanical environment for Autonomous Sensorimotor Discovery. Rather than a mere toy, the cube is defined as a high-dimensional state-space system where a robotic agent must learn to navigate through physical interactions.
