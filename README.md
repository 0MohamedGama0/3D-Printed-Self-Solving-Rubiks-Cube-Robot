# 🧩 3D Printed Self-Solving Rubik's Cube Robot

A low-cost, educational robotic platform for studying physical reasoning through Rubik's Cube manipulation. This project combines **3D printing, embedded systems, and machine learning** to create a scientific instrument for learning action-consequence models.

## 🎯 Key Features

- **🛠️ Low-Cost Design**: ~¥400 total cost
- **🧪 Scientific Instrument**: Designed for studying physical reasoning
- **📊 Data Collection**: Self-supervised transition dataset generation
- **🎓 Educational**: Complete tutorial for STEM education
- **🔬 Research-Ready**: Framework for learning physical dynamics

- Python 3.8+
- Arduino IDE 2.0+
- SolidWorks/Fusion 360 (optional for modifications)
